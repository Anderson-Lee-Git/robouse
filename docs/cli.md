# robouse CLI

`robouse` runs tasks, episodes and trials. The help blocks below are the output of `robouse 0.1.0`, generated by `scripts/cli_reference.py`.

```console
$ robouse --help
usage: robouse [-h] [--version] {serve,run,run-many,tasks,fetch-assets} ...

robo-use: agent as a policy for embodied agents. Runs robot tasks with an
agent harness as the policy. https://robouse.ai

positional arguments:
  {serve,run,run-many,tasks,fetch-assets}
    serve               run one trusted episode server (used by `run`)
    run                 run one trial end to end
    run-many            run a set of trials
    tasks               list tasks (default: the bundled tasks)
    fetch-assets        download the MuJoCo Menagerie meshes used by the
                        menagerie, RoboHarm and drone suites

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
```

## robouse run

```console
$ robouse run --help
usage: robouse run [-h] --task TASK --harness HARNESS [--model MODEL] --out
                   OUT [--timeout TIMEOUT] [--seed SEED]

options:
  -h, --help         show this help message and exit
  --task TASK
  --harness HARNESS
  --model MODEL
  --out OUT
  --timeout TIMEOUT
  --seed SEED
```

- `--task`: a task folder, or the id of a bundled task (`robouse tasks` lists them).
- `--harness`: `oracle`, `noop`, `claude-code`, `codex`, `claude-code-glm`, `codex-glm`, `mini-swe-agent-glm` or `molmoact2`; see [Harnesses](harnesses.md).
- `--model`: the model for `claude-code` and `codex`; the other harnesses ignore it.
- `--out`: the job folder; the trial is written to `OUT/<task>__<harness>__<id>/`.
- `--timeout`: the agent's wall-clock limit in seconds (default: the task's `agent.timeout_sec`, else 900).
- `--seed`: overrides the task's `seed` (object and goal layout).

It prints a JSON summary (`trial`, `reward`, `outcome`, `steps`, `wall_s`, `exception`). A non-null `exception` means the trial could not start; it is not a score.

## robouse run-many

```console
$ robouse run-many --help
usage: robouse run-many [-h] [--tasks TASKS] --harness HARNESS [--model MODEL]
                        --out OUT [--filter FILTER] [--limit LIMIT]
                        [--concurrency CONCURRENCY] [--timeout TIMEOUT]
                        [--task-list TASK_LIST] [--resume]

options:
  -h, --help            show this help message and exit
  --tasks TASKS         task root (default: the bundled tasks)
  --harness HARNESS
  --model MODEL
  --out OUT
  --filter FILTER
  --limit LIMIT
  --concurrency CONCURRENCY
  --timeout TIMEOUT
  --task-list TASK_LIST
                        file with one task id per line (subset of --tasks)
  --resume              skip tasks that already have a finished, non-infra-
                        failed trial in --out
```

- `--tasks`: a folder of task folders, searched recursively (default: all bundled tasks).
- `--filter`: only task ids containing this substring. `--task-list`: only the ids in this file.
- `--limit`: at most this many tasks (0: all). `--concurrency`: trials in parallel (default 1).
- `--harness`, `--model`, `--out`, `--timeout`: as for `run`.

It prints one line per finished trial, appends it to `OUT/run_log.jsonl`, and ends with the number solved.

## robouse tasks

```console
$ robouse tasks --help
usage: robouse tasks [-h] [--path] [root]

positional arguments:
  root        task root (default: the bundled tasks)

options:
  -h, --help  show this help message and exit
  --path      print the bundled task directory and exit
```

Prints one line per task: id, backend, simulator env id (empty for tabletop tasks).

## robouse fetch-assets

```console
$ robouse fetch-assets --help
usage: robouse fetch-assets [-h] [--dest DEST]

options:
  -h, --help   show this help message and exit
  --dest DEST  target directory (default: ~/.cache/robouse/menagerie or
               $ROBOUSE_MENAGERIE_ASSETS)
```

Downloads the MuJoCo Menagerie robot models (about 42 MB) that the `menagerie`, `roboharm` and `drone` suites need, each checked by SHA-256. Files already present are skipped. The episode server looks in `$ROBOUSE_MENAGERIE_ASSETS`, else `~/.cache/robouse/menagerie`.

## robouse serve

```console
$ robouse serve --help
usage: robouse serve [-h] --task TASK --run-dir RUN_DIR --socket SOCKET
                     [--workspace WORKSPACE] [--seed SEED]
                     [--max-wall-s MAX_WALL_S] [--ready-file READY_FILE]

options:
  -h, --help            show this help message and exit
  --task TASK
  --run-dir RUN_DIR
  --socket SOCKET
  --workspace WORKSPACE
  --seed SEED
  --max-wall-s MAX_WALL_S
  --ready-file READY_FILE
```

Runs one episode server on a Unix socket until the episode ends, then prints the verdict as JSON. `run` starts it for you; use it directly to drive a robot by hand with `robo` (set `ROBOUSE_SOCKET` to the socket path).
